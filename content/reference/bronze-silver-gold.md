# Bronze, Silver and Gold branch site topologies

Gathered 2026-10-20 for step 17. **Question asked: are "Bronze", "Silver" and "Gold" documented vendor terms or a training-course convention?** **Answer: they are documented vendor terms.** They appear in a "Branch Site Topologies" section of the Administration Guide in the VMware SD-WAN 3.4 guide (read directly) and in the Arista 7.0 Administration Guide Overview (summarised via WebFetch). They are **not** used in the 7.0 "Site Configurations Overview" page, which names the same kind of site "Hybrid Site-1", "Hybrid Site-2" and so on (see `site-topologies.md`). The details a course says about each label, beyond the vendor text below, are design practice.

**Read directly**: VMware SD-WAN 3.4 Administration Guide (PDF, Broadcom legacy archive, 2020), pages 29 to 33 and 332 to 333. **Summarised via WebFetch**: Arista 7.0 Overview (two windows, 0 to 153454 characters of which the topologies section sits after 100000), Arista 7.0 and 5.2 Site Configurations pages. The 6.4 Overview was not read (a search snippet of the 6.1 Overview shows the same section; not opened).
