# Troubleshooting: documented causes and common issues

Read: Only documented causes. The 7.0 Troubleshooting Guide has no chapter of known issues; the items below come from the test descriptions, the events appendix and the Orchestrator and Gateway guides. Activation, link flapping, tunnel, NAT, MTR, MTU, DNS, time, certificate and license issues are covered only as far as a source says.
