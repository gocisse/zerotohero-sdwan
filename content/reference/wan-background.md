# WAN background

Why traditional branch WANs struggled. Most rows come from one Arista solution brief (an official vendor document, so it states the vendor's view of the problem).

| claim | source URL | doc version | status |
|---|---|---|---|
| WAN technologies used in most branches changed little in decades; they were originally designed for applications in private, on-premises data centers. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| MPLS typically gives high-quality service but with limited capacity, higher cost and long deployment lead times. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| Branches that only have private circuits backhaul cloud, SaaS and Internet traffic through the enterprise data center, which adds latency, degrades application performance and raises bandwidth cost. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| A traditional hub-and-spoke WAN architecture might not support cloud migration. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| Broadband gives fast deployment and greater capacity but can lack reliability, security and assured performance, causing a poor user experience. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| Most branch WAN traffic is carried over leased lines such as private MPLS circuits, or over Internet connections such as DSL, cable and LTE; neither is ideal alone. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| Branch users consume more WAN bandwidth through collaboration apps (the brief names Zoom, WebEx, Microsoft 365), SaaS, cloud services and large media files. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| Traditional branch networks lack centralized management, control, visibility and protection; too many management tools make troubleshooting and incident response slow. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
| Compliance regimes such as PCI, HIPAA and GDPR are hard to maintain across many branches that use different security products from different vendors. | https://www.arista.com/assets/data/pdf/SD-WAN-Solution-Overview.pdf | solution brief (undated) | VERIFIED |
