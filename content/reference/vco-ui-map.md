# VCO UI map (7.0 documentation)

Where concepts live in the Orchestrator, as named in the 7.0 guides. Labels can differ between releases and between guides.

| claim | source URL | doc version | status |
|---|---|---|---|
| The enterprise-facing screens described are in the "SD-WAN service of the Enterprise portal". | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-monitor-enterprise | 7.0 | VERIFIED |
| Monitor > Network Overview summarizes activated Edges, links, top applications and Edges by traffic; it has a Traffic Usage tab and a Configuration Data tab (profiles used, segments, software versions, HA and VNF flags, non-SD-WAN destinations via Gateway). | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-monitor-enterprise | 7.0 | VERIFIED |
| Monitor > Security Overview summarizes IDS/IPS, URL filtering and malicious-IP threats; it requires the EFS feature to be enabled in Global Settings. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-monitor-enterprise | 7.0 | VERIFIED |
| Monitor > Edges lists Edges with status, links and Gateways; opening an Edge gives tabs Overview (link status, bandwidth), QoE (voice, video, transactional quality), Links (WAN link metrics, incl. a transport-group view), Paths (paths to SD-WAN peers), Flows, Applications, Sources, Destinations, Business Priority and System. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-monitor-enterprise | 7.0 | VERIFIED |
| An Edge has a Shortcuts menu with Configure, View Events, Remote Diagnostics, Generate Diagnostic Bundle, Remote Actions, View Profile and View Gateways. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-monitor-enterprise | 7.0 | VERIFIED |
| Monitor > Network Services lists Non SD-WAN Destinations through Gateway, Non SD-WAN Destinations through an Edge, Cloud Security Service Sites, Zscaler IaaS Subscription, Edge Clusters and Edge VNFs. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-monitor-enterprise | 7.0 | VERIFIED |
| Configure > Edges lists Edges; an Edge's Overview tab is where the activation email is sent; an Edge also has a Business Policy tab. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-activate-edges | 7.0 | VERIFIED |
| Configure > Profiles: a Profile is a template applied to many Edges; the list has a Used By column and View links for Device, Business Policy and Firewall; a profile opens on a Device tab and also has an Overview tab; a default Quick Start Profile exists after installation. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-configure-profiles | 7.0 | VERIFIED |
| Business policy is reached at Configure > Edges > (an Edge) > Business Policy tab, or at Configure > Profiles > Business Policy. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-configure-business-policy | 7.0 | VERIFIED |
| A business-policy rule has an Action tab with the Link Steering choices (Auto, Transport Group, Interface, WAN Link). | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-configure-business-policy | 7.0 | VERIFIED |
| Configure > Overlay Flow Control is the overlay routing view. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-overview | 7.0 | VERIFIED |
| Cloud VPN settings (Branch to Hub, Branch to Branch, dynamic branch-to-branch) are under the device settings of a Profile, per Segment. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-configure-device-settings-for-profiles | 7.0 | VERIFIED |
| Diagnostics: the testing chapter says the entry point is the "Diagnostics" tab with Remote Diagnostics (run tests on a chosen Edge) and Diagnostic Bundles (PCAP and diagnostic bundles); Remote Actions (Identify, Restart Service, Reboot, Shutdown, Deactivate, Force HA Failover) are reached from the Edge Shortcuts menu. | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-testing-and-troubleshooting | 7.0 | VERIFIED |
| The 7.0 role-matrix table labels areas "Monitor > Edges", "Configure > Edges", "Test & Troubleshoot > Remote Diagnostics" and "Administration > System Settings". | https://www.arista.com/en/admin-guide-vc-7-0/sd-wan-7-0-overview | 7.0 | VERIFIED |
