# Edge models and sizing

Gathered 2026-10-20 for step 17. **Read directly**: the two Arista datasheets were downloaded as PDFs and their text extracted by us (page numbers are the PDF pages). **Summarised via WebFetch**: Arista HTML pages (the site blocks automated browsers; verbatim quotes were requested and the tool paraphrases some). Datasheet dates: both PDFs print "Oct 16th 2026" with document numbers 04-0063-07 (7x0) and 04-0062-06 (4100, 5100) and "Copyright 2025". Both say Edges must be on software code **R7.0.0** to achieve the listed performance. Model families change: re-read the current datasheet before quoting a figure.

No `reference-sources/` folder exists. No Edge datasheet for models older than the 7x0, 4100 and 5100 families (for example 5x0, 6x0, 840, 2000, 3x00) could be found on arista.com; those models appear only in the 7.0 Administration Guide tables (summarised) and in the HA platform list.
