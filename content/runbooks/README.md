# Runbooks

One-page references for troubleshooting, shown in the app under /troubleshooting. Each file is `<id>.mdx` with frontmatter `id`,
`title`, `summary`, `kind` (checklist, cheatsheet, template or reference) and `estimated_minutes`, then an MDX body (it can use
`<Term id>`, `<Callout>` and `<Diagram id>`). They are validated with the rest of the content (all errors at once). The runbooks are
this course's own working aids; the tables of tools and options in them come only from VERIFIED or OBSERVED rows of
`content/reference/troubleshooting/`. A runbook never states an output format that is not in an official document or an
observation file.
