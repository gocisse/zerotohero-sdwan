<Term id="debug-py">debug.py</Term> is named in Arista documents, but only a few options are described for the **Edge**. This page lists what is documented, labelled by device, and keeps everything else in a separate list that you fill in from your own observation. No output format is shown here: the documents print the outputs as figures or JSON for the Gateway only.

<Callout variant="warning" title="Read-only only">
  Run only what a document or Support asked for. Activating a device from its command line (activate.py), restarting services, rebooting and clearing tables are state-changing and out of scope for this course.
</Callout>

## Documented for the Edge or the Gateway command line

| Option | Device | What the documentation says | Source | Status |
|---|---|---|---|---|
| `--pki` | Edge or Gateway | shows PKI settings, the trusted CA list and the certificate | Orchestrator Guide 7.0, page 142 | VERIFIED |
| `--ike_sa` | Edge or Gateway | shows the details of current security associations | Orchestrator Guide 7.0, page 142 | VERIFIED |
| `--ike_spd` | Edge or Gateway | shows details of the security protocols and encryption methods used per peer | Orchestrator Guide 7.0, pages 142 and 143 | VERIFIED |
| `--routes` | named only | the Troubleshooting Guide refers to "the debug.py--routes output" for route flags; syntax and output are not documented | Troubleshooting Guide 7.0, page 88 | VERIFIED |

## Documented for the Gateway only

These run on the Gateway as the user vcadmin, from /opt/vc/bin/debug.py. The Gateway Monitoring Guide warns that some commands and example outputs may only be relevant to Release 5.0.0. They are **not** documented for an Edge.

| Option | Device | Used in the guide for | Source | Status |
|---|---|---|---|---|
| `--icmp_monitor` | Gateway | ICMP probe state, UP or DOWN | Gateway Monitoring Guide 7.0, page 20 | VERIFIED |
| `--bgp_view_summary` | Gateway | counting established BGP sessions | Gateway Monitoring Guide 7.0, page 21 | VERIFIED |
| `--handoff` | Gateway | the handoff queue (with -v; omit -v for a table) | Gateway Monitoring Guide 7.0, page 24 | VERIFIED |
| `--list_edges` | Gateway | the number of connected Edges | Gateway Monitoring Guide 7.0, page 27 | VERIFIED |
| `--vrf` | Gateway | counting BGP VRFs | Gateway Monitoring Guide 7.0, page 29 | VERIFIED |
| `--stale_nat_dump` | Gateway | stale NAT entries, collected with a diagnostic bundle for support | Gateway Monitoring Guide 7.0, page 32 | VERIFIED |
| `--path` | Gateway | path details such as the latency thresholds (with -v) | Gateway Monitoring Guide 7.0, page 34 | VERIFIED |
| `--dpdk_ports_dump` | Gateway | used inside a script in the guide | Gateway Monitoring Guide 7.0, page 17 | VERIFIED |
