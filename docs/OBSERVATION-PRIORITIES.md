## How the ranking works

Items that block the most content come first. `score` = for an **assumption**: 10 per lab that relies on it + 6 per engine rule + 2 per place in the engine that cites it + 3 per lesson (a lab's goal lessons, or a lesson that names the assumption) + 1 per quiz question tied to those lessons. For a **VERIFY row**: 6 per not-modelled engine rule built on it + 2 per engine citation + 1 per lesson of the section(s) the sheet backs (section-level, because lessons are not tagged with rows) + 1 per lab in those sections. Labs never depend on a VERIFY row (the lab validator rejects an answer that does), so a VERIFY row ranks by what the engine withholds.

Quiz questions never rest on a VERIFY row or an assumption (their answers use VERIFIED rows only); the count shows how many questions sit in the affected lessons and should be re-read if an observation corrects something.
